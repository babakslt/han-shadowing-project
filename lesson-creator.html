Import Chinese + English, generate YAML, then produce audio with `main.py`.

1. Paste Sentences

Each line should contain Chinese + English. Optional third column for pinyin. Use CSV or TSV.

Tip: You can paste from spreadsheets. Tabs are supported automatically.

2. Review & Export

Rows: 0
Chinese Pinyin (optional) English

3. Generate Audio Files

After downloading the YAML, place it in the `yaml/` folder and run:

python main.py yaml/your_lesson.yaml

This will generate MP3 files into the `audio/` folder.

4. Use in Player

Open `index.html` or `memory-activator.html` and add the YAML with the "+" button.
